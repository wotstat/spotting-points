# WotStat Spotting Points

Габаритные и обзорные точки выбранного танка в ангаре «Мира танков» и WoT.

Откройте ModsList и нажмите **«Включить/выключить габаритные точки»**.
Повторное нажатие убирает отображение. При запуске игры мод выключен.
Красные сферы — габаритные точки, голубые — обзорные (включая совпадающие
с габаритными). Белые линии показывают BBox корпуса и верхнюю плоскость,
серые — диагонали и направляющие из SpottingUtil (`showBBoxes` + `showBBoxAlign`).
Скрытые бронёй сферы и поперечная направляющая видны более бледно;
остальные линии проверяют глубину, как в источнике. Смена танка и поворот башни
обрабатываются автоматически. За пределами ангара отрисовка останавливается.

Нужен [ModsList API](https://docs.wotstat.info/guide/integrations/mods-list/).
Собственной иконки нет: ModsList показывает свой стандартный значок.
Полная подпись может обрезаться штатной однострочной кнопкой ModsList;
назначение также указано во всплывающей подсказке.

## Установка

- «Мир танков»: `dist/wotstat.spotting-points_0.1.1.mtmod` → `mods/<версия игры>/`.
- WoT: `dist/wotstat.spotting-points_0.1.1.wotmod` → `mods/<версия игры>/`.

Пакет устанавливайте при закрытой игре. При обновлении после переименования
удалите из папки игры пакет с прежним именем, чтобы не загрузить две копии мода.
Других зависимостей, кроме ModsList,
нет. Отрисовка адаптирована из ангарной части локального `wotstat-debug-utils`;
его UI, ресурсы, боевые вычисления и модуль `gui.debugUtils` не включены.
Мод не перекрывает штатные файлы клиента и не устанавливает monkey patches.

## Разработка

Сборка из PowerShell, Python 2.7:

```powershell
./build.ps1 -Version 0.1.1 -Python C:/Python27/python.exe
C:/Python27/python.exe -B -m unittest discover -s tests
```

Сборка копирует `res` в `.build`, подставляет версию, компилирует staged-файлы
и формирует два ZIP_STORED пакета в `dist`. Исходники остаются без байткода.

В VS Code откройте `mir-tankov.code-workspace` или `world-of-tanks.code-workspace`.
Профили подключают только один продукт: соседние каталоги `../wot-src-ru`
и `../wot-src-eu` соответственно. Пути проверены; работа Pylance в интерфейсе
редактора в этой сессии не проверялась.

## Проверка

Python 2.7: три теста геометрии (асимметричный корпус, смещения компонентов,
высота верхней точки, все 13 полилиний BBox и направляющих, цвета и проходы).
Runtime через WotStat REPL 1.4.1 в MT 1.45.0.0:
загрузка пакета, реальная кнопка ModsList, смена Strv 103B/Orso,
двухпроходные сферы, положение точки при повороте башни, остановка callback
и снятие регистрации проверены. После перезапуска финальный пакет проверен
на Т-62А: включение и выключение реальной кнопкой, отсутствие дублирующихся
подписок и ошибок мода в интервале финального прогона.

В версии 0.1.1 дополнительно проверены BBox и все 13 полилиний на
120 AC Gendarme, изображение в ангаре и выключение/включение через
зарегистрированный callback ModsList. Установленный MT-пакет совпадает
по SHA256 со сборкой в `dist`.

Контракты WoT сверены с локальными исходниками ветки `wot-eu` 2.3.1.3;
в самом WoT мод пока не тестировался.

После переименования в `wotstat.spotting-points` оба пакета пересобраны:
проверены metadata, пути модулей и отсутствие прежних идентификаторов в архиве.
Три теста геометрии прошли на Python 2.7. В запущенном MT 1.45.0.0 через REPL
проверены импорт из нового `.mtmod`, регистрация нового ID, создание контроллера
и очистка через `fini()`. Автоматическая загрузка нового пакета после перезапуска
клиента в рамках переименования не проверялась.
