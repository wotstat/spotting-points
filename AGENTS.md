# Работа с запущенным клиентом

Для быстрых итераций этого мода используй WotStat REPL MCP. Проверенный порядок
обновления Python и AS3/SWF без перезапуска описан в
[docs/live-reload.md](docs/live-reload.md). Прочитай его перед обновлением кода
в работающем клиенте.

Не считай сборку или копирование пакета обновлением запущенной игры: проверь,
что клиент действительно исполняет новый код. Сохраняй пользовательские настройки
при пересоздании мода. Не перезапускай клиент, если достаточно обновить наш мод.

Тестовые файлы и классы для обхода кэша держи в `.local/`, не включай их в релиз.
После проверки сообщай отдельно о текущей сессии и готовом пакете в `dist`:
обновление через REPL не устанавливает пакет для следующего запуска игры.
