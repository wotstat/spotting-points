# План реализации Spotting Points

Цель: самостоятельный ангарный мод по [design.md](design.md).
Стек: Python 2.7, DebugDrawer, ModsList API, Scaleform/AS3, PowerShell.

- [x] Геометрия: geometry.py получает локальные bbox корпуса/башни и смещения;
  формирует фиксированные габаритные точки и направляющие. Проверить
  асимметричный корпус и смещения отдельными Python 2 тестами.
- [x] renderer.py преобразует координаты и выводит пары сфер/линий через
  DebugDrawer. controller.py владеет callback и событиями IHangarSpace.
  bootstrap.py регистрирует ModsList один раз; тонкий mod entry вызывает init/fini.
- [x] build.ps1 и tools/package.py: staging, версия, Python 2 py_compile,
  ZIP_STORED в dist для обоих расширений. Добавить профили IDE по продуктам.
- [x] Установить mtmod в тестовый клиент, запустить через REPL, проверить
  загрузку, реальную кнопку, включение/выключение, смену танка и углов,
  скриншот и хвост лога. Проверить содержимое архивов. Описать ограничения.
- [x] Добавить несохраняемое состояние четырёх флагов и независимую
  фильтрацию точек/направляющих; покрыть чистую логику Python 2.7 тестами.
- [x] Добавить захват drag только на башне/орудии, применение yaw/pitch
  в пределах дескриптора и блокировку камеры только во время такого drag.
- [x] Создать уникальное немодальное Scaleform-окно и скомпилировать его
  против SWC целевого MT-клиента.
- [x] Подключить окно к ModsList, собрать 0.2.0 и через MCP WotStat REPL 1.4.1
  проверить UI, рендеринг, вращение, пределы углов, очистку и сброс после
  перезапуска.
- [x] Перенести механику drag из EU-просмотра брони: башня меняет только yaw,
  орудие меняет yaw/pitch, а направление учитывает сторону точки захвата.
- [x] Вернуть единое управление yaw/pitch при захвате башни или орудия,
  убрать зависимость направления от места захвата и удвоить чувствительность.
- [x] Восстановить отдельную статичную габаритную точку крепления орудия,
  сохранив динамическую обзорно-габаритную точку на живом `GUN_JOINT`.
