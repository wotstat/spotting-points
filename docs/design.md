# WotStat Spotting Points

Python 2.7 мод для ангара «Мира танков» и WoT. Единственное управление —
пункт ModsList «Включить/выключить габаритные точки», без иконки и окна.
По умолчанию выключен; состояние сохраняется только в текущем запуске игры.

Геометрия повторяет ангарную часть SpottingUtil из wotstat-debug-utils:
габаритные точки красные, обзорные голубые, направляющие относительно
габаритов корпуса. BBox и направляющие повторяют все 13 полилиний
`showBBoxes` + `showBBoxAlign`: белые границы корпуса и верхней плоскости,
серые диагонали и привязки точек. Из линий только поперечная направляющая
имеет бледный проход, остальные проверяют глубину, как в источнике.
Для сфер два прохода DebugDrawer: бледный без проверки глубины
и яркий с проверкой. Совпадающие обзорные и габаритные точки показываются
голубыми сферами. UI, боевые вычисления и зависимость debug-utils
не входят в мод.

Controller получает только выбранный танк через IHangarSpace. Пока включён,
рисует каждый кадр; проверяет готовность модели, пересчитывает координаты
при изменении углов башни и трансформации танка. Событие уничтожения ангара
останавливает callback, создание ангара возобновляет его. Выключение и fini
снимают callback; fini снимает подписки и регистрацию ModsList.

Источники: ../wot-src-ru (mt-ru, 1.45), ../wot-src-eu (wot-eu, 2.3).
Контракты: IHangarSpace, ClientSelectableCameraVehicle, HangarVehicleAppearance,
CollisionComponent.getBoundingBox, TankNodeNames.GUN_JOINT, realm.CURRENT_REALM.
WoT использует обратный порядок проходов из исходного DrawerController.
Runtime тестируется только MT 1.45, совместимость WoT требует будущего прогона.
